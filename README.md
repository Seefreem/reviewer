# 功能描述
这是一个用于复习英语的APP。

目前只开发了基于文字的复习功能，未来打算开发基于图片、音频和视频的功能。

目前知识全都存放在 data/ko.json 文件中。未来计划引入数据库。

# 使用方法
S1 安装对应的依赖库(请看源码)
S2 直接运行main.py文件就好

# 单词本

程序默认打开 `data/ko.json`。窗口顶部提供两个单词本管理按钮：

- `新增单词本`：选择新 JSON 文件的位置，并设置名称、描述、源语言、目标语言和标签。
- `选择单词表`：打开已有的单词表 JSON 文件。

单词表本身继续使用原有的 JSON 数组格式。新建单词本的元数据保存在同目录、同名的
`.meta.json` 文件中。例如 `ielts.json` 的元数据文件是 `ielts.meta.json`。没有元数据
文件的旧单词表仍然可以直接打开。

保存、关闭时保存以及切换前保存都会写入当前选中的单词表，而不再固定写入
`data/ko.json`。
